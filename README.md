# Neha & Abhishek — Wedding Invitation

A responsive, single-page wedding invitation site made with plain HTML, CSS and JavaScript. It is ready to publish with GitHub Pages.

## Included interactions
- Live countdown to the first celebration
- Mobile navigation
- Click-to-expand photo gallery (original photographs)
- RSVP form that builds a message and lets guests copy it to share
- Venue link that opens a Google Maps search for Auric Resort, Kota
- Subtle falling petals, with reduced-motion support

## Publish at `github.io`
1. Sign in to GitHub and create a **public** repository named `YOUR-USERNAME.github.io` (or any repository name if you prefer a project site).
2. Upload the contents of this folder — `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder — to the repository root.
3. For a project repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. For a user site named `YOUR-USERNAME.github.io`, GitHub Pages usually publishes from the root of `main` once enabled.
4. Wait a minute or two. Your site will be at `https://YOUR-USERNAME.github.io/` (user site) or `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/` (project site).

## Personalise before publishing
- RSVP currently creates a copyable message; it does not send responses to a database. Add a Formspree endpoint or your preferred form backend if you want automatic collection.
- Confirm the exact resort map pin and replace the Google Maps search link if you have a direct venue link.
- The Ghibli-inspired artwork is an AI-created interpretation of the garba moment. The ring and beach photos are the original uploaded photographs; the gallery lets visitors open the original images.
